Gu-disk 0.1.0 —— Windows 硬盘全检工具
================================================

【怎么运行】
  1. 把整个文件夹解压到任意位置（例如 D:\Gu-disk）
  2. 双击 Gu-disk.exe

  ※ 不要只把 exe 单独拖出来放 —— 它需要同级的 data\ 与 tools\smartctl\。
  ※ 不需要预装 .NET：运行时已经打进包里了。

【要不要管理员权限】
  不需要也能看 NVMe 固态的全部信息（本工具用原生 IOCTL 直读健康日志与身份信息）。

  下面这些功能需要管理员：
    · SATA / 机械硬盘的 SMART 透传
    · 硬盘自检（短检 / 扩展检）
    · AAM / APM 调速
    · 裸盘全盘扫描

  要用这些时：右键 Gu-disk.exe → 以管理员身份运行；
  或者先普通启动，在【设置 → 系统工具】里点「以管理员身份重启」。
  启动时窗口右上角会显示当前是否受限。

【数据写到哪】
  默认写到程序同级的 data\ 目录（便携：不写注册表、不碰系统盘）。
  如果程序装在 Program Files 这类没有写权限的位置，会自动改用
  %LOCALAPPDATA%\Gu-disk。
  想强制指定位置：设环境变量 GUDISK_HOME=<目录>。

【包里有什么】
  Gu-disk.exe        主程序
  data\              属性特征库、驱动特征库索引、语言包 + 你的历史/设置/日志
  tools\smartctl\    smartmontools 的 smartctl.exe（兜底引擎，并与原生引擎交叉校验）
  使用说明.txt        本文件

【界面七个页面】
  硬盘概览 · S.M.A.R.T. · 自检与工具 · 基准测速 · 坏道扫描 · 诊断报告 · 设置

  另外：设置里可以打开「桌面温度悬浮窗」，在桌面常驻显示温度，
  温度这一路的刷新间隔是独立的（只走原生引擎，约 20 毫秒一次），
  可以设得比整体诊断密得多。

【状态怎么看】
  不给分数。状态是四档：正常 / 注意 / 警告 / 危急，
  每一项都会写明「来源 SMART 字段 → 原始值 → 判读 + 建议」，
  正常项也会列在「已核对项」里，让人看见核对了什么。

【卸载】
  删掉整个文件夹即可 —— 注册表和系统目录都没动过。
  如果用过 %LOCALAPPDATA%\Gu-disk，一并删掉。

本工具不安装任何内核驱动，全部走用户态 DeviceIoControl。
