Gu-disk 0.2.6 —— Windows 硬盘全检工具
================================================

【怎么运行】
  1. 把整个文件夹解压到任意位置（例如 D:\Gu-disk）
  2. 双击 Gu-disk.exe

  ※ 不要只把 exe 单独拖出来放 —— 它需要同级的 data\ 与 tools\smartctl\。
  ※ 本包是「自包含」版：不需要预装 .NET，运行时已经打进来了。
    另有约 1 MB 的「框架依赖」版，功能完全相同，但需预装 .NET 9 桌面运行时。

【强烈建议以管理员身份运行】
  右键 Gu-disk.exe → 以管理员身份运行；
  或者双击同目录的 run-gudisk.cmd（会自动申请提权）。
  也可以先普通启动，在【设置 → 系统工具】里点「以管理员身份重启」。

  不需要管理员的：NVMe 固态的全部信息（原生 IOCTL 直读健康日志与身份）。
  需要管理员的：
    · SATA / 机械硬盘的 SMART 透传
    · USB 硬盘盒（桥接芯片要求打开设备才能穿桥读 SMART —— 这是硬件限制，
      CrystalDiskInfo 同样要求提权）
    · 硬盘自检（短检 / 扩展检）
    · AAM / APM 调速
    · 裸盘全盘扫描

  启动时窗口右上角会显示当前权限状态。

【数据写到哪】
  默认写到程序同级的 data\ 目录（便携：不写注册表、不碰系统盘）。
  如果程序装在 Program Files 这类没有写权限的位置，会自动改用
  %LOCALAPPDATA%\Gu-disk。
  想强制指定位置：设环境变量 GUDISK_HOME=<目录>。

【包里有什么】
  Gu-disk.exe        主程序
  data\              属性特征库、驱动特征库索引、语言包 + 你的历史/设置/日志
  tools\smartctl\    smartmontools 的 smartctl.exe（兜底引擎，并与原生引擎交叉校验）
  使用说明.txt        本文件

【界面七个页面】
  硬盘概览 · S.M.A.R.T. · 自检与工具 · 基准测速 · 坏道扫描 · 诊断报告 · 设置

  另外：设置里可以打开「桌面温度悬浮窗」，在桌面常驻显示温度，可逐盘勾选。
  温度这一路的刷新间隔是独立的（约 20 毫秒一次），可以设得比整体诊断密得多。

【S.M.A.R.T. 页怎么看】
  列与 CrystalDiskInfo 对应：
    ID · 属性名称 · 当前值 · 最差值 · 临界值 · 原始值（十进制）· 原始值（十六进制）· 状态
  「临界值」是判断还剩多少余量的依据；NVMe 属性没有这套阈值体系，显示为 "-"。

  更详细的版本见仓库 docs\功能对照清单.md。

【状态怎么看】
  不给分数。状态是四档：正常 / 注意 / 警告 / 危急，
  每一项都会写明「来源 SMART 字段 → 原始值 → 判读 + 建议」，
  正常项也会列在「已核对项」里，让人看见核对了什么。

  注意：通电时间很长（如超过 3 年）也会判「注意」，这是有意的保守提示，
  不代表介质有问题 —— 具体看 0x05 重映射 / 0xC5 待处置 / 0xC6 不可校正 是否为零。

【卸载】
  删掉整个文件夹即可 —— 注册表和系统目录都没动过。
  如果用过 %LOCALAPPDATA%\Gu-disk，一并删掉。

本工具不安装任何内核驱动，全部走用户态 DeviceIoControl。
