# 参照软件 → Gu-disk 移植清单

原则：**能直接拿的就直接拿**，落点必须是 `src/`（翻译成 C# / XAML）或 `data/`（JSON），
`reference/extracted/` 只存原件、不参与构建。移植代码在文件头标注来源。

提取脚本：`node tools/extract-reference.mjs` → 产出 `reference/extracted/` + `tools/smartctl/`（已跑通，22 切片 + 2 复制）。

## 1. 数据与库

| 来源 | 内容 | 落点 | 方式 |
|---|---|---|---|
| CDI `Simplified Chinese.lang` | `[Smart]` 通用表 + `[SmartNVMe]` + 43 个厂商节的属性中文名；`[Dialog]`/`[DiskStatus]`/`[Message]`/`[Alarm]`/`[Graph]` 文案 | `data/smart-attributes.json`、`data/i18n/zh-CN.json` | 脚本转换（`tools/convert-lang.ps1`，待写） |

| CDI `DiskInfo.ini` | `[USB]` / `[Setting]` 开关全清单 | `GuDisk.Core/Smart/QuirkProfiles.cs` 的枚举与默认值 | 直接映射 |
| CDM `SimplifiedChinese.lang` | 基准页文案与选项名 | `data/i18n/zh-CN.json` 基准节 | 脚本转换 |
| CDM `theme.ini` + `Themes/Default/*.png` | 按钮/仪表/注释皮肤令牌 | XAML 控件模板的**视觉参照**（不贴图） | 参照 |
