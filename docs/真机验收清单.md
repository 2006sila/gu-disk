# Gu-disk 真机验收清单

沙箱内没有管理员权限，SMART 透传 / 裸盘扫描 / 写基准的**实测必须在有管理员的机器上做**。
每项验收都贴**原始命令输出**，不要只打勾。

## 0. 通用准备

```
1. 以管理员身份启动 Gu-disk（内嵌 requireAdministrator，正常双击即可）
2. 先跑一遍基线：Gu-disk.Cli list --json  → 确认设备枚举与桥接识别
3. 对照标尺：同一台机器上跑 CrystalDiskInfo（参考软件/CrystalDiskInfo/DiskInfo64S.exe）
   与 CrystalDiskMark（参考软件/CrystalDiskMark/DiskMark64S.exe），结果并排截图
```

## A. NVMe 直连（三块盘，已有硬件）

| # | 验收项 | 判据 | 结果 |
|---|---|---|---|
| A1 | 型号 / 序列号 / 固件 | 与 CDI **逐字符一致** | ☐ |
| A2 | 接口 / 标准 / 传输模式 | 与 CDI 一致（PCIe 链路速率与宽度要对） | ☐ |
| A3 | 通电时间 / 通电次数 | 与 CDI 一致；确认单位未被误判为分钟 | ☐ |
| A4 | 温度（综合 + 各传感器） | 与 CDI 一致；缺项显示 N/A | ☐ |
| A5 | 主机读写总量 | 与 CDI 一致（换算用 512 000 B/data unit） | ☐ |
| A6 | 21 项 NVMe Health Log 字段 | 中文名与 CDI 逐字一致 | ☐ |
| A7 | 状态判定 | 四档状态正确；每条判定依据都能在属性表里找到对应原始值 | ☐ |
| A8 | 双引擎交叉校验 | Native 与 smartctl 字段全一致（或差异被标注） | ☐ |
| A9 | 读取耗时 | Native ≤ 100 ms | ☐ |
| A10 | 趋势采样 | 连续采样 3 点写入 history CSV 且可绘图 | ☐ |

设备：Predator SSD GM7 2TB ／ KIOXIA EXCERIA PLUS G3 ／ YMTC YMSS2E

| # | 验收项 | 判据 | 结果 |

| # | 验收项 | 判据 | 结果 |
|---|---|---|---|
